# AURAPEPT · Calculateur de reconstitution

Calculateur de reconstitution au thème japonais : concentration, graduation à prélever sur seringue U-100, seringue animée, étiquette de flacon imprimable.

Site statique d'une seule page (`index.html`), sans dépendance à installer. Les polices viennent de Google Fonts.
